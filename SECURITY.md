# Security Policy

## Supported Versions

Omnix is currently under active development.
Security updates are applied to the latest production version.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

Please do NOT create public GitHub issues for security vulnerabilities.

You can report vulnerabilities through:
- GitHub private vulnerability reporting
- Direct contact with repository maintainers

## Response Process

Reported vulnerabilities will be reviewed and addressed as quickly as possible.

Security fixes may include:
- dependency updates
- infrastructure patches
- authentication fixes
- API security improvements

## Security Best Practices

Omnix uses:
- GitHub Secret Scanning
- Dependabot alerts
- CodeQL analysis
- Push protection
- Production environment isolation

Please avoid sharing:
- API keys
- secrets
- credentials
- production tokens
